## Publish with GitHub Pages

1. Log into GitHub and create a new public repository named `retentionlens-lab5`.
2. Upload **the contents of this folder**, keeping `index.html`, `about.html`, `style.css`, `app.js`, and `assets/` in the repository's top level. Do not upload only the ZIP file.
3. In the repository go to **Settings → Pages → Build and deployment**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
5. After GitHub Pages reports the site live, open the published URL in a private browser. Test homepage film autoplays and loops, "Inside the system" navigation, all scenario sliders, and live chatbot on **both** pages.
6. Enter the verified published GitHub Pages URL in Canvas and submit.

Project URL usually follows: `https://YOUR-USERNAME.github.io/retentionlens-lab5/`. Replace YOUR-USERNAME with your actual GitHub username; this is not a verified published link.

## Economic model disclosure

The Case Lab is an educational assumption calculator, not a predictive AI model or causal estimate. At-risk revenue = customers × churn rate × monthly revenue/customer. Modeled recovered revenue = at-risk revenue × assumed relative churn reduction. Modeled net = recovered revenue − intervention cost, annualized by multiplying by 12 under constant assumptions. Real retention economics require customer cohorts, contribution margin, intervention efficacy, and experimental evidence.
