# RetentionLens

RetentionLens is an educational business decision-intelligence prototype. The Class 5 website includes an AI-generated looping concept video, a browser-based scenario lab, a two-page product explainer, and links to a chatbot built using Chatling.

## Status

Early-stage prototype and roadmap; not a production AI deployment.

## Website

This repository is intended for GitHub Pages publication at https://marvelprince-bit.github.io/retentionlens/ .

## Note

Financial outputs from the scenario lab are illustrative, not causal estimates or investment advice.
